# Java: от основ языка до веб- и мобильных приложений

Репозиторий объединяет два самостоятельных, взаимосвязанных курса:
**«Разработка на Java»** (`Java_course`) и **«Разработка мобильных приложений
на Java»** (`Java_mobile`). Первый формирует базу языка и ведёт к серверному
и веб-приложению. Второй применяет знания Java в разработке Android-приложений.

Общая учебная линия — моделирование данных, обработка событий и ошибок,
хранение информации и обмен данными через HTTP. Курсы показывают, как эти
задачи решаются в разных средах: на сервере, в браузерном интерфейсе и на
мобильном устройстве.

## Два курса и их результаты

| | Java_course | Java_mobile |
|---|---|---|
| Направление | Основы Java, серверная и веб-разработка | Мобильная разработка для Android |
| Объём | 24 лекции и 24 практических занятия, всего 96 академических часов | 5 лекций (0–4) по 90 минут, практика и домашние задания |
| Основные темы | Типы, ООП, коллекции, Stream API, файлы, JVM, параллельность, тестирование, JDBC, HTTP и REST | Activity и её жизненный цикл, XML-интерфейс, события, навигация, RecyclerView, локальное хранение и REST-клиент |
| Прикладной стек | Maven, Spring Boot, PostgreSQL, JPA, Spring Security, Vaadin Flow | Gradle, Android SDK, Java/XML, Room, Retrofit |
| Итог | Полнофункциональное веб-приложение со сквозным проектом и защитой | Мини-проект «Личная библиотека» |

В мобильном курсе основной маршрут построен на Java и XML layouts.
Kotlin и Jetpack Compose рассматриваются как контекст и следующий шаг обучения.

## Как курсы связаны

Знания типов, классов, интерфейсов, коллекций и исключений из `Java_course`
понадобятся при создании моделей, обработчиков и адаптеров в `Java_mobile`.
Работа с файлами, тестирование и понимание фоновых операций помогают перейти
к хранению данных и сетевым запросам на Android.

Связь особенно хорошо видна на прикладных задачах:

| Общая задача | В серверном и веб-курсе | В мобильном курсе |
|---|---|---|
| Представить предметную область | Java-модель, сервисы и бизнес-правила | Модели данных и логика приложения |
| Сохранить данные | PostgreSQL, JDBC, JPA и транзакции | Локальная база Room и DAO |
| Обменяться данными | Создание REST API на Spring Boot | Обращение к REST API через Retrofit |
| Показать данные пользователю | Веб-интерфейс Vaadin | Android-экраны на XML и RecyclerView |

Для общей практики можно расширить серверный проект REST API и подключить
к нему Android-клиент. Это дополнительный сценарий интеграции: готовые примеры
в репозитории запускаются отдельно, а мобильный `library-client` обращается
к внешнему Gutenberg API через RapidAPI.

## Рекомендуемый порядок обучения

1. Пройти темы 1–15 в `Java_course`: основы языка, стандартную библиотеку,
   JVM, параллельность и тестирование.
2. Продолжить темы 16–21: базы данных, HTTP, REST и Spring Boot. Эти знания
   помогут понять взаимодействие мобильного клиента с сервером.
3. Изучить `Java_mobile` последовательно, от лекции 0 до лекции 4:
   первый экран → события и состояние → списки и навигация → Room → Retrofit.
4. Завершить темы 22–24 в `Java_course`: Vaadin, архитектура приложения
   и защита итогового проекта. Этот блок можно проходить параллельно
   с мобильным курсом после освоения серверной части.

Если основы Java уже знакомы, мобильный курс можно изучать отдельно.
При этом нужно учитывать особенности Android: жизненный цикл компонентов,
ограничения UI-потока и доступные API отличаются от обычного Java-приложения.

## Окружение и запуск примеров

Для `Java_course` используются **JDK 25 LTS и Maven 3.9.x**. Для итогового
веб-проекта также нужны Docker с Docker Compose, PostgreSQL 18 и Node.js 24+
для Vaadin 25. Каждый каталог в `Java_course/examples/` — отдельный
Maven-проект; команды запуска приведены в его README.

Для `Java_mobile` нужны **Android Studio, Android SDK и эмулятор либо физическое
устройство**. Демонстрационные проекты используют Android SDK 35 и JDK 17.
Открывайте в Android Studio каталог конкретного приложения из
`Java_mobile/examples/`, дождитесь Gradle Sync и запустите модуль `app`.
Особенности запуска из Windows/WSL описаны в README примеров.

Настройки JDK выбираются для каждого проекта отдельно: требования серверного
курса и Android-примеров различаются. Сетевой пример `library-client` требует
настройки доступа к API по [инструкции проекта](Java_mobile/examples/library-client/README.md).

В корне нет единой сборки для двух курсов. Начните с README выбранного курса,
затем переходите к лекции, соответствующему примеру и практическому заданию.
