# Лекция 14: concurrency и virtual threads

Требования: JDK 25 и Maven 3.9.x.

```bash
mvn test
mvn compile exec:java
```

Тесты без случайных задержек демонстрируют потерянное обновление, три безопасных
счётчика, наблюдение исключения через `Future.get()`, отмену с прерыванием и
ограничение нагрузки через `Semaphore`. `CountDownLatch` задаёт требуемое
чередование; timeout используется только для защиты теста от зависания.

Приложение печатает результаты 20 задач и измеренный пик, не превышающий 4.
