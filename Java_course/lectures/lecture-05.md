# Лекция 5. Ссылочные типы строки массивы и перечисления

Версия для чтения. Основа: [рекомендации к лекции 5](lecture-05.md).

**Цель:** Понимать различие значения ссылки и объекта, правильно сравнивать строки.

## Основные понятия

Переменная ссылочного типа хранит не объект, а ссылку на него либо `null`.
Несколько переменных могут указывать на один изменяемый объект, поэтому изменение
через одну ссылку видно через другую. `NullPointerException` возникает при
попытке обратиться к члену через `null`; лучше не маскировать его повсеместными
проверками, а определить, где отсутствие значения допустимо по контракту.

`String` неизменяем. Операции `strip`, `replace` и `toUpperCase` возвращают результат строкой и не изменяют исходную строку; новый объект создаётся не обязательно. Оператор `==` сравнивает значения ссылок, а `equals` — содержимое строк.
Интернирование может случайно сделать `==` истинным для литералов, поэтому такой
код особенно опасен: тест иногда проходит, хотя контракт неверен.

Повторная конкатенация строк в цикле создаёт много промежуточных объектов.
`StringBuilder` накапливает результат изменяемо, а в конце создаёт строку через
`toString`. Text block удобен для многострочного JSON или SQL, но отступы и
конечный перевод строки остаются частью значения и требуют проверки.

Массив имеет фиксированную длину и хранит элементы одного типа. Индексы идут от
нуля до `length - 1`. Многомерный массив Java — массив ссылок на массивы, поэтому
строки могут иметь разную длину. Массивы изменяемы; передача внутреннего массива
наружу нарушает инкапсуляцию.

`enum` задаёт закрытый набор экземпляров. Это полноценный тип: он может иметь
поля, конструктор и методы. `Status.valueOf` чувствителен к регистру и бросает
исключение для неизвестного значения; пользовательский ввод обычно нормализуют
или разбирают отдельным методом с понятной диагностикой.

## От модели к решению

### Равенство и накопление строк

Две строки с одинаковым содержимым могут быть разными объектами. Поэтому `new String("Java") == new String("Java")` даёт false, а equals — true. Интернирование литералов иногда делает `==` случайно успешным и маскирует ошибку. Для сравнения с возможным null подходит `Objects.equals(a, b)`.

`strip` возвращает строку без краевых пробелов и не меняет исходный объект. StringBuilder удобен для накопления текста в цикле. Пустой результат ещё не означает, что ни один элемент не обработан: первая строка массива тоже может быть пустой. Поэтому разделитель в примере определяется индексом, а не длиной накопленного текста.

Text block с тройными кавычками удобен для многострочного SQL или JSON. Он остаётся обычной строкой: отступы и завершающий перевод строки влияют на содержимое, а вставка пользовательских значений требует подходящего API.

### Массивы и enum

Длина массива фиксирована при создании; индексы идут от нуля до `length - 1`. Двумерный массив — массив ссылок на другие массивы: строки могут иметь разную длину и быть null. Копия внешнего массива не копирует вложенные массивы глубоко.

`Status.valueOf("DONE")` возвращает константу, неизвестный текст вызывает IllegalArgumentException. При допустимом разном регистре нужна явная нормализация, например с Locale.ROOT. Константы enum допустимо сравнивать через `==`; правило сравнения строк через equals не запрещает эту идиому.

Enum может иметь поля, конструктор и методы, например отображаемое название. `ordinal()` опасно сохранять как постоянный код: перестановка констант меняет его смысл.

В задании используется упрощённый формат `name;status`. Это не полноценный CSV с кавычками и многострочными полями. `split(";", -1)` сохраняет пустое последнее поле. Для настоящего CSV нужен парсер формата.

## Практический пример

Ниже приведён учебный фрагмент. Структура проекта, зависимости и команды запуска находятся в [проекте лекции 5](../examples/lecture-05-references-strings-arrays/README.md).

```java
enum Status { NEW, IN_PROGRESS, DONE }

public class Words {
    static String join(String[] values) {
        var result = new StringBuilder();
        java.util.Objects.requireNonNull(values, "values");
        for (int i = 0; i < values.length; i++) {
            if (i > 0) result.append(", ");
            result.append(java.util.Objects.requireNonNull(values[i], "element").strip());
        }
        return result.toString();
    }
}
```

## Разбор и проверка результата

### Разбор результата join

Для массива `{" Java ", " SQL "}` метод возвращает `Java, SQL`. Исходный массив и его строки остаются прежними: нормализованные значения добавляются в отдельный накопитель. Пустой массив даёт пустую строку. Null вместо массива или вместо элемента явно отклоняется.

Массив `{"", "Java"}` возвращает `, Java`: пример сохраняет позиции пустых строк, а не фильтрует их. Это позволяет отделить соединение элементов от выбора допустимых данных. Если задача требует пропускать пустые названия, фильтрация добавляется как отдельное правило до join.

Для статуса DONE следует различать текст из файла и значение enum. Текст сначала проверяется и преобразуется; дальше программа работает с типом Status, где неизвестного статуса уже нет. На границе ввода диагностическое сообщение сохраняет исходное значение, чтобы пользователь мог исправить запись.

## Типичные ошибки

- строки сравниваются через `==`;
- результат `strip()` игнорируется;
- выход за границы массива;
- внутренний массив возвращается без защитной копии;
- `valueOf` используется для непроверенного пользовательского ввода.
