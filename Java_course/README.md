# Курс «Разработка на Java»

Курс ведёт студента от первого запуска Java-программы до небольшого
полнофункционального веб-приложения на Spring Boot, PostgreSQL и Vaadin Flow.

## Объём

- 24 лекции по 2 академических часа (2 × 45 минут = 90 минут каждая);
- 24 практических занятия по 2 академических часа;
- всего 96 академических часов;
- итоговый сквозной проект.

Практика является отдельным занятием: её время не включается в 90 минут лекции.
Внутри каждой главы приведён самостоятельный лекционный сценарий от 0 до 90
минут, включающий изложение теории, демонстрацию, разбор ошибок и вопросы.

## Требования к окружению

- JDK 25 LTS;
- Maven 3.9.x (точную версию сверяйте через `mvn --version`);
- Docker с Docker Compose;
- PostgreSQL 18 для итогового проекта;
- Node.js 24+ для занятий с Vaadin 25;
- IDE с поддержкой Maven либо терминал.

Версии Spring Boot и Vaadin фиксируются в стартовом проекте преподавателя перед
началом набора и не обновляются посреди семестра.

## Рекомендуемый маршрут

1. Темы 1–8: основы языка и проектирование объектов.
2. Темы 9–15: стандартная библиотека, JVM, параллельность и тестирование.
3. Темы 16–17: база данных и веб-протоколы без фреймворка.
4. Темы 18–21: Spring Boot REST-приложение.
5. Темы 22–24: Vaadin UI, эксплуатация и защита проекта.

## Граница базового Core-раздела

Темы 1–15 сохраняют текущий объём вводного курса. Новая библиотека или идиома
добавляется в обязательную часть только под конкретный проверяемый учебный
результат; более глубокий обзор библиотек и проектных приёмов остаётся в
самостоятельном чтении и практических расширениях.
