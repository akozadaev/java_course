# Тема: Ссылочные типы, строки, массивы и перечисления

**Цель темы.** Понимать различие ссылки и объекта; корректно сравнивать строки.

**Общая постановка.** Работайте со строками через `equals`/`equalsIgnoreCase`, не через `==`. Пустые и null-элементы обработайте явно. Результат стабилен при повторном запуске.
