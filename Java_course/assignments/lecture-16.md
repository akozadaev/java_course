# Тема: SQL, JDBC и транзакции

**Цель темы.** Параметризованные запросы и границы транзакций.

**Общая постановка.** Только PreparedStatement для пользовательского ввода. Миграции идемпотентны. Частичный заказ не остаётся при сбое.
