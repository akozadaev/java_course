# Тема: Дата, время, локализация и регулярные выражения

**Цель темы.** Корректно работать с зонами, форматами и вводом.

**Общая постановка.** Используйте `java.time` (`Instant`/`ZonedDateTime`/`ZoneId`). Формат явный. Некорректный ввод не даёт необработанного исключения.
