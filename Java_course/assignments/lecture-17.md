# Тема: HTTP, REST и основы веб-приложений

**Цель темы.** Спроектировать HTTP API до Spring.

**Общая постановка.** Контракт различает 400/404/409. JSON + Content-Type. Имена ресурсов во множественном числе. Для JPMS — `requires jdk.httpserver` при модуле.
