# Тема: Обобщения, коллекции и equals/hashCode

**Цель темы.** Выбирать коллекцию по операциям; типобезопасный API; корректные ключи Map.

**Общая постановка.** Ключи Map неизменяемы. Наружу не отдавать внутреннюю mutable коллекцию. Политика null зафиксирована. Тест воспроизводит проблему изменяемого ключа.
