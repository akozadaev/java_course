# Тема: Spring Data JPA, миграции и транзакции

**Цель темы.** Сопоставить модель и БД без скрытых N+1.

**Общая постановка.** Схема только миграциями. `@Transactional` на сервисе. Тесты на PostgreSQL. Нет LazyInitializationException в выбранном сценарии. Поля entity — private.
