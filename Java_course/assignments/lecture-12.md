# Тема: Файлы, потоки, NIO и сериализация данных

**Цель темы.** Читать/писать файлы без утечек; избегать небезопасной Java serialization.

**Общая постановка.** Кодировка UTF-8 явная. JSON через библиотеку (Gson/Jackson) или простой ручной формат — не `ObjectOutputStream` для доменных данных. Повреждённый ввод — диагностическая ошибка.
