# Тема: Модули, рефлексия, аннотации и JVM

**Цель темы.** Понимать границы модулей, метаданные и базовую модель JVM.

**Общая постановка.** Разделите API и реализацию. Клиент не компилируется при доступе к internal. Рефлексию используйте дозированно; в README — риск хрупкости.

## Варианты

**Задание.** Сценарий «API + impl модули». exports только API; provides/uses опционально. Оформите решение отдельным Maven-модулем или проектом по общим правилам `assignments/README.md`; в README варианта укажите команды запуска/тестов и какие граничные случаи проверены.

**Критерии приёмки.** Обращение к internal не компилируется; запуск заявленной командой.
