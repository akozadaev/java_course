# Тема: Переменные, примитивные типы и операторы

**Цель темы.** Выбирать тип данных и объяснять преобразования и переполнение.

**Общая постановка.** Реализуйте денежный расчёт на `BigDecimal` (без `float`/`double` для денег). Покройте тестами обычное значение, ноль и дробный налог/ставку. В README кратко объясните, почему `double` здесь недопустим.

## Варианты

### Вариант 1. Заказ с налогом

**Задание.** Сценарий «Заказ с налогом». Цена позиции × количество + налог %. Итог с scale 2, `RoundingMode.HALF_UP`. Оформите решение отдельным Maven-модулем или проектом по общим правилам `assignments/README.md`; в README варианта укажите команды запуска/тестов и какие граничные случаи проверены.

**Критерии приёмки.** Нет ошибок двоичной плавающей точки; тесты на 0% и дробный %.

### Вариант 2. Обмен валют

**Задание.** Сценарий «Обмен валют». Конвертируйте сумму в другой валюте: amount × rate. Результат с scale 2 и HALF_UP. Курс и сумму задавайте строками BigDecimal. Оформите решение отдельным Maven-модулем или проектом по общим правилам `assignments/README.md`; в README варианта укажите команды запуска/тестов и какие граничные случаи проверены.

**Критерии приёмки.** `BigDecimal` из строки; нулевой или отрицательный курс отклоняется; тест на типичный курс.

### Вариант 3. Сложные проценты (2 периода)

**Задание.** Сценарий «Сложные проценты (2 периода)». Сумма × (1 + rate) дважды; rate — `BigDecimal`. Оформите решение отдельным Maven-модулем или проектом по общим правилам `assignments/README.md`; в README варианта укажите команды запуска/тестов и какие граничные случаи проверены.

**Критерии приёмки.** Сравнение через `compareTo`, не `equals` с разным scale.

### Вариант 4. Разделение счёта

**Задание.** Сценарий «Разделение счёта». Сумма делится на N человек с scale 2; остаток копеек отдаётся первому. Оформите решение отдельным Maven-модулем или проектом по общим правилам `assignments/README.md`; в README варианта укажите команды запуска/тестов и какие граничные случаи проверены.

**Критерии приёмки.** Сумма частей равна исходной; N≤0 отклоняется.

### Вариант 5. Скидка и налог

**Задание.** Сценарий «Скидка и налог». От цены сначала примените скидку в процентах, затем налог в процентах. Зафиксируйте порядок в тестах (скидка→налог, не наоборот). Оформите решение отдельным Maven-модулем или проектом по общим правилам `assignments/README.md`; в README варианта укажите команды запуска/тестов и какие граничные случаи проверены.

**Критерии приёмки.** Порядок операций зафиксирован тестом; только `BigDecimal`; scale 2.

### Вариант 6. Период подписки

**Задание.** Сценарий «Период подписки». Цена за месяц × месяцев; при ≥12 месяцах скидка 15%. Оформите решение отдельным Maven-модулем или проектом по общим правилам `assignments/README.md`; в README варианта укажите команды запуска/тестов и какие граничные случаи проверены.

**Критерии приёмки.** Граничный случай 11 и 12 месяцев в тестах.

**Задание.** Сценарий «Конвертация кг ↔ г». Храните массу как граммы (`long`), для вывода в кг используйте `BigDecimal`.
