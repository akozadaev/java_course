# Тема: Исключения, контракты и ресурсы

**Цель темы.** Разделять ожидаемые ошибки и дефекты; не терять причину; закрывать ресурсы.

**Общая постановка.** Опишите предусловия/постусловия метода. try-with-resources обязателен для I/O. Ошибка открытия файла не маскируется пустым успешным результатом.

## Варианты

### Вариант 1. Разбор файла заказов

**Задание.** Сценарий «Разбор файла заказов». Корректные строки + список ошибок с номерами строк. Оформите решение отдельным Maven-модулем или проектом по общим правилам `assignments/README.md`; в README варианта укажите команды запуска/тестов и какие граничные случаи проверены.

**Критерии приёмки.** Ресурс закрыт; контракт в Javadoc; причина при wrap сохранена.
