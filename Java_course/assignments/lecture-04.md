# Тема: Условия, циклы, методы и область видимости

**Цель темы.** Разбивать решение на методы и управлять ходом выполнения.

**Общая постановка.** Разбейте решение на небольшие методы без дублирования условий. Покройте граничные значения тестами или демонстрационным запуском, описанным в README.

## Варианты

### Вариант 1. Оценки: min/max/avg и буква

**Задание.** Сценарий «Оценки: min/max/avg и буква». Список оценок 0–100 → минимум, максимум, среднее и категория A–F. Оформите решение отдельным Maven-модулем или проектом по общим правилам `assignments/README.md`; в README варианта укажите команды запуска/тестов и какие граничные случаи проверены.

**Критерии приёмки.** Границы 0, 59, 60, 89, 90, 100 проверены; нет копипасты порогов.

### Вариант 2. FizzBuzz до N

**Задание.** Сценарий «FizzBuzz до N». Метод возвращает список строк по правилам FizzBuzz. Оформите решение отдельным Maven-модулем или проектом по общим правилам `assignments/README.md`; в README варианта укажите команды запуска/тестов и какие граничные случаи проверены.

**Критерии приёмки.** N=15 покрыт тестом; логика кратности в отдельных предикатах/методах.

### Вариант 3. Поиск простых

**Задание.** Сценарий «Поиск простых». Метод принимает N и возвращает список всех простых чисел от 2 до N включительно. Проверку простоты вынесите в отдельный метод. Оформите решение отдельным Maven-модулем или проектом по общим правилам `assignments/README.md`; в README варианта укажите команды запуска/тестов и какие граничные случаи проверены.

**Критерии приёмки.** N<2 → пустой список; N=10 → [2,3,5,7]; без дублирования циклов.

**Задание.** Сценарий «Таблица умножения». Постройте двумерный массив int[n][n], где ячейка [i][j] = (i+1)*(j+1). Печать таблицы — только в main, не в методе построения.
