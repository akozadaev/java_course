# Тема: Тестирование Java-кода

**Цель темы.** Писать быстрые воспроизводимые тесты; отделять unit от integration.

**Общая постановка.** Тесты независимы от порядка. Падение показывает expected/actual. Интеграция с БД — Testcontainers или аналог без ручной локальной настройки.

## Варианты
