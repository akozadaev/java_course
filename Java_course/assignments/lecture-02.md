# Тема: Оформление кода и инструменты проекта

**Цель темы.** Оформлять код по единым правилам и собирать проект Maven.

**Общая постановка.** Создайте Maven-проект с пакетом `course.demo`, классом расчёта предметной величины, Javadoc на публичном API и тестом JUnit. `mvn verify` должен проходить. Имена отражают назначение; неиспользуемых импортов нет.

## Варианты

### Вариант 1. Стоимость доставки

**Задание.** Сценарий «Стоимость доставки». Метод считает доставку: база + цена за кг * вес. Тест: обычный вес, ноль, отрицательный вес (исключение). Оформите решение отдельным Maven-модулем или проектом по общим правилам `assignments/README.md`; в README варианта укажите команды запуска/тестов и какие граничные случаи проверены.

**Критерии приёмки.** `mvn verify` успешен; Javadoc у публичного метода; форматирование единообразно.
