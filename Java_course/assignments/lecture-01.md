# Тема: Платформа Java и первый запуск

**Цель темы.** Различать JDK, JVM и стандарт Java SE; скомпилировать и запустить программу без IDE.

**Общая постановка.** Напишите консольную программу на Java 25. Выведите версию среды (`System.getProperty("java.version")`) и результат предметного расчёта по аргументам командной строки. Ошибку числа аргументов обработайте понятным сообщением и ненулевым кодом завершения.
