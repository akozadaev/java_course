# Тема: Наследование, интерфейсы и композиция

**Цель темы.** Использовать полиморфизм и выбирать композицию вместо лишнего наследования.

**Общая постановка.** Полиморфизм заменяет цепочки `instanceof`. Новая стратегия — новый класс без правки сервиса. Публичных изменяемых полей нет.
