# Тема: Сборка, контейнеризация и итоговый проект

**Цель темы.** Собрать воспроизводимый релиз и защитить архитектурные решения.

**Общая постановка.** `mvn verify` и `docker compose up` из чистого клона. Контейнер не root. Health отражает готовность БД. README: предпосылки, пользователи, ограничения.

Оформите решение отдельным Maven-модулем или проектом по общим правилам `assignments/README.md`; в README варианта укажите команды запуска/тестов и какие граничные случаи проверены.
