# Тема: Классы, объекты, записи и неизменяемость

**Цель темы.** Проектировать состояние объекта и поддерживать инварианты.

**Общая постановка.** Недопустимое состояние нельзя создать. Изменяемые коллекции снаружи не ломают объект (защитные копии / `List.copyOf`). Деньги — `BigDecimal`.

## Варианты

### Вариант 1. Order с защитной копией

**Задание.** Сценарий «Order с защитной копией». Сравните «дырявый» Order и исправленный с `Order.of` и стоимостью позиции. Оформите решение отдельным Maven-модулем или проектом по общим правилам `assignments/README.md`; в README варианта укажите команды запуска/тестов и какие граничные случаи проверены.

**Критерии приёмки.** Мутация входного списка после создания не меняет заказ; accessor не отдаёт mutable list.
