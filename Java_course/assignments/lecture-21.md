# Тема: Безопасность, конфигурация и наблюдаемость

**Цель темы.** Защитить API и диагностировать без утечки секретов.

**Общая постановка.** Тесты отличают 401 и 403. Пароли только как hash. Health без секретов. Метрики с ограниченной кардинальностью label. SecurityContextHolder по умолчанию ThreadLocal — учитывать.
