# Тема: Spring Core и Spring Boot

**Цель темы.** Контейнер зависимостей и минимальное Boot-приложение.

**Общая постановка.** Constructor injection. Профили извне. Без циклов. `@Service` в отдельном файле. `mvn spring-boot:run` работает.
