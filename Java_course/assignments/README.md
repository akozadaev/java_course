# Практические задания для самостоятельной работы

Курс: **Разработка на Java**.

На каждую тему подготовлено **10 вариантов**. Студент выполняет один вариант,
назначенный преподавателем (обычно по номеру в журнале: `N mod 10`, где 0 → вариант 10).

## Общие требования ко всем вариантам

1. Решение оформляется как отдельный Maven-проект (или расширение проекта примера лекции),
   если иное не указано в варианте.
2. Код компилируется и запускается без IDE: `mvn -q test` или `mvn -q exec:java` /
   команда из README варианта.
3. Имена классов, методов и переменных отражают предметную область варианта.
4. Неверные входные данные дают понятное сообщение, а не необработанное исключение
   (для тем после лекции 8 — с сохранением причины).
5. В README варианта: что сделано, как запустить, какие граничные случаи проверены.
6. Копирование чужого варианта целиком не допускается; на защите студент объясняет код
   и меняет одно правило по запросу преподавателя.

## Критерии оценивания варианта (10 баллов)

| Критерий | Баллы |
|---|---:|
| Соответствие формулировке варианта | 3 |
| Корректность и граничные случаи | 3 |
| Читаемость и структура кода | 2 |
| README и способ проверки | 2 |
