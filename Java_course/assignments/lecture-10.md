# Тема: Функциональные интерфейсы, лямбды и Stream API

**Цель темы.** Строить понятные конвейеры без побочных эффектов.

**Общая постановка.** Не мутировать внешние коллекции внутри map/filter. Сложный участок — именованный метод. null не заменяет пустую коллекцию. Учесть null-ключи в groupingBy.
