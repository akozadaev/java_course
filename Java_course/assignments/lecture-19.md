# Тема: REST API на Spring MVC

**Цель темы.** Контроллеры, валидация DTO, единообразные ошибки.

**Общая постановка.** Не отдавать JPA entity. `@Valid`. 201 на создание с телом ответа (например ProductResponse с id). MockMvc-тесты обязательны.
