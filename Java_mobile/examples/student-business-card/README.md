# Приложение-визитка

Учебный пример к домашнему заданию лекции 0. Проект написан на Java, а экран — на XML.

На экране представлены:

- имя студента — Козадаев Алексей;
- группа 007;
- профессиональные интересы и краткая биография;
- кнопка «Показать приветствие» без обработчика нажатия, как предусмотрено заданием.

## Запуск

1. Откройте Android Studio.
2. Выберите **Open** и каталог `examples/student-business-card`.
3. Дождитесь синхронизации Gradle.
4. При необходимости установите Android SDK 35 по предложению Android Studio.
5. Запустите конфигурацию `app` на эмуляторе или физическом устройстве.

Ключевые файлы:

- `app/src/main/java/ru/akozadaev/businesscard/MainActivity.java` — Activity;
- `app/src/main/res/layout/activity_main.xml` — разметка экрана;
- `app/src/main/res/values/strings.xml` — весь пользовательский текст.
