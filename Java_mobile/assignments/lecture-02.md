# Тема: Экраны: UI и навигация

**Цель темы.** Список, деталь, передача данных, Activity Result API.

**Общая постановка.** RecyclerView + Adapter; переход на деталь; возврат результата через Activity Result API (не deprecated startActivityForResult). Зависимость recyclerview указана явно при необходимости. Launcher регистрируется до onStart.

## Варианты

### Вариант 1. Список студентов

**Задание.** Сценарий «Список студентов». ≥10 студентов; деталь: имя, группа, email, балл; Result — имя выбранного. Создайте Android-проект (Empty Views Activity, Java + XML) по общим правилам `assignments/README.md`; в README варианта укажите minSdk/compileSdk, как запускать и что проверено на эмуляторе или устройстве.

**Критерии приёмки.** Result API; поворот на списке не теряет данные (in-memory ok если восстановлены).
