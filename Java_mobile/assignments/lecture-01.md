# Тема: Разработка простого приложения на Java

**Цель темы.** Собрать интерактивный UI: виджеты, обработчики, состояние Activity.

**Общая постановка.** Приложение с пользовательским вводом и отображением результата. Состояние переживает поворот экрана (`onSaveInstanceState` / ViewModel — на выбор курса, минимум — bundle). Граничные значения обрабатываются.
