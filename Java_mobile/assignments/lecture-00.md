# Тема: Введение в мобильную разработку

**Цель темы.** Сформировать представление о платформе Android, структуре проекта и среде Android Studio.

**Общая постановка.** Создайте проект Empty Views Activity (Java). Подготовьте короткую записку (1–2 страницы в README) и минимальный экран, подтверждающий запуск на эмуляторе или устройстве. Зафиксируйте версии Android Studio / JDK / compileSdk.
