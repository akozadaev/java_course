# Практические задания для самостоятельной работы

Курс: **Разработка мобильных приложений на Java** (Android, XML, Java).

На каждую тему подготовлено **10 вариантов**. Студент выполняет один вариант,
назначенный преподавателем (обычно `((N - 1) % 10) + 1`).

## Общие требования

1. Язык UI и логики: **Java** + **XML layouts** (не Compose как основной путь).
2. Шаблон проекта: **Empty Views Activity**, язык Java.
3. В README: как собрать/запустить, целевой minSdk/compileSdk, что проверено на эмуляторе/устройстве.
4. На защите студент объясняет жизненный цикл затронутых компонентов и меняет одно требование.
5. Сетевые запросы и Room — вне UI-потока; для REST нужен `INTERNET` (и HTTPS по возможности).

## Критерии оценивания варианта (10 баллов)

| Критерий | Баллы |
|---|---:|
| Соответствие варианту | 3 |
| Стабильность (поворот, back, пустые состояния) | 3 |
| Структура кода и ресурсы | 2 |
| README и демонстрация | 2 |
