# Тема: Работа с локальной базой данных

**Цель темы.** SharedPreferences для настроек; Room для сущностей; фон для DAO.

**Общая постановка.** Room: Entity (пустой конструктор или полный), DAO, Database с exportSchema=false, singleton getInstance. Executor/shutdown в onDestroy. Запросы не на UI-потоке. SharedPreferences — реальное значение, не константа.
