# Ключи и чеклисты преподавателя — Разработка мобильных приложений на Java

Документ для внутреннего использования. Студентам достаточно банка в `assignments/lecture-*.md` и рекомендуемого варианта в тексте лекции.

## Как принимать работу

1. Студент сдаёт вариант, назначенный по журналу, **или** рекомендуемый вариант лекции, если поток идёт единым ДЗ.
2. На защите: объяснить 2–3 ключевых решения и изменить одно правило по запросу.
3. Шкала 10 баллов — в `assignments/README.md`.
4. Ниже для каждой темы: рекомендуемый вариант, чеклист приёмки, типичные сбои, вопросы на защите.

## Лекция 0. Введение в мобильную разработку

**Рекомендуемый вариант:** 1. Визитка разработчика

**Суть:** Экран: ФИО, группа, 3 интереса, кнопка «Показать приветствие» (Toast или Snackbar).

### Чеклист приёмки (рекомендуемый вариант)

- [ ] Проект собирается
- [ ] README с версиями
- [ ] Скрин/описание запуска
- [ ] Код запускается заявленной командой без IDE-магии
- [ ] Студент объясняет решение своими словами

### Типичные сбои

- Работа сделана «в целом по теме», но не по формулировке варианта
- Нет проверки граничных/ошибочных входов
- README без команд воспроизведения
- На защите не удаётся изменить одно правило

### Вопросы на защите
