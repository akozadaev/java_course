# Курс «Разработка мобильных приложений на Java»

Курс ведёт студента от введения в Android до небольшого Java/XML-приложения с
локальной базой Room и REST-клиентом Retrofit.

## Объём

- 5 лекций (0–4) по 90 минут (2 академических часа);
- практические работы и домашние задания в каждой лекции;
- итоговый мини-проект «Личная библиотека».

Линия курса: Java, Activity, XML-layout, RecyclerView, Room, Retrofit.
Современный маршрут Google (Kotlin + Jetpack Compose) даётся как контекст и
рекомендуемый следующий шаг, а не как обязательный стек первой линии.

## Навигация

- [`presentations/`](presentations/) — презентации Marp;
- [`examples/`](examples/) — демонстрационные Android-проекты;

## Требования к окружению

- Android Studio актуальной стабильной версии;
- JDK из комплекта Android Studio;
- Android SDK Platform и AVD либо физическое устройство.

## Генерация производных материалов

```bash
make help
make build-textbook      # manuscript/*.md и *.docx
make validate-textbook
make regenerate          # презентации + рукопись
```

## Практические задания для самостоятельной работы

На каждую лекцию подготовлено **10 вариантов** заданий: каталог [`assignments/`](assignments/README.md).
Вариант назначается преподавателем (формула в README каталога).
